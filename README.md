# 🎊 Digital Menu - Carnaval da Débora

Este é um projeto de **Cardápio Digital Interativo** desenvolvido sob medida para dispositivos móveis. O objetivo foi transformar um design estático (imagem 15x20cm) em uma experiência web fluida, responsiva e festiva.

---

## 🚀 Demonstração
Você pode visualizar o projeto online aqui:
> **🔗 https://julianas1229.github.io/cardapio-carnaval01/**

---

## ✨ Características
* **📱 Mobile-First:** Desenvolvido exclusivamente para visualização impecável em smartphones.
* **🎭 Design Vibrante:** Identidade visual baseada na temática de Carnaval, com cores saturadas e elementos festivos.
* **⚡ Performance:** Construído com código limpo (HTML/CSS puro) para carregamento instantâneo.
* **🖱️ Interatividade:** Efeitos de hover e transições suaves ao navegar pelas opções de drinks.

---

## 🍸 Itens do Cardápio
* **Clássicos:** Aperol Spritz, Moscow Mule, Negroni, Campari.
* **Caipirinhas:** Diversos sabores (Limão, Morango, Kiwi, Maracujá, Abacaxi).
* **Energéticos:** Combinações potentes com Gin e Vodka.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, Flexbox para responsividade e animações.
* **JavaScript:** Pequenas interações e efeitos de interface.
* **AI Assisted:** Design e estrutura refinados com auxílio de Inteligência Artificial.
